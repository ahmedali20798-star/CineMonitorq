# CanonMultiCam Pro (V19 — Production Release)

Professional 4-Camera Cinema Monitor & Controller for Canon EOS Cameras (R5C, R6 II, C200, R5, R6, R8) on Android.

## Key Capabilities
- **Quad-Protocol Multi-Cam Engine (Up to 4 Cameras):** Simultaneously mix **Wi-Fi CCAPI**, **Browser Remote (R5C Video / C200)**, **PTP/IP**, and wired **USB-C OTG (USB PTP)**.
- **Priority Preemption USB Engine:** Instant `REC ALL`, `Touch AF`, and hexadecimal ISO/Kelvin control over USB without LiveView bus starvation.
- **OpenGL ES 3.0 Cinema Monitoring:** Real-time `.cube` 3D LUTs, Focus Peaking (R/G/B/W), False Color, **Dynamic Zebra (`70%` Skin / `95%` Highlight via long-press)**, 3x3 / 9:16 / 2.39:1 Frame Guides, and Anamorphic De-squeeze (`1.33x`, `1.5x`, `2.0x`).
- **Marathon Stress-Tested Architecture:** 30Hz coalesced GL render pipeline, double-buffered native memory pool, WakeLock USB/Wi-Fi protection, Take Logger with Premiere Pro CSV Marker export, and Thermal Guard.
